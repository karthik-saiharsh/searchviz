A stupid simple site that provides an interactive interface to visualize and see various search algorithms in action using game playing agents.

Algorithms Available:
- MiniMax (Tic-Tac-Toe Game)

Algorithms Planned:
- BFS (8 Puzzle Game)
- DFS (8 Puzzle Game)
- A* (8 Puzzle Game)
- Bi-Directional Search (8 Puzzle Game)
- Constraint Satisfaction Problems
